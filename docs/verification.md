# Calculation verification

## Method

The source edition, equations and tabulated values are identified in [coverage.md](coverage.md). AS 1720.1 contains tabulated material properties and the numeric parallel-system illustration in Figure 2.3, but no worked numerical beam or column design. The example cases below are therefore explicitly **independent worked verification cases**, not examples published in the standard.

The cases use F17 hardwood and, for bearing, seasoned Blackbutt's SD2 strength group from Appendix H. The member dimensions and design actions are illustrative. Expected values are independently calculated from the cited equations and table values, then compared with the package result at tight numerical tolerance by the test suite and `tests/verification_report.py`. Tests also exercise factor boundaries, schema rejection and the plugin descriptor contract.

## Worked cases

| Case | Inputs | Independent cross-check |
|---|---|---|
| Beam | F17 hardwood, seasoned, category 2, 5-month duration, EMC 18%; 90 × 240 mm; 8 kN·m major-axis moment, 15 kN shear; compression-edge restraint at 400 mm | Eq. 3.2(2), Eq. 3.2(4)/(6), Eq. 3.2(10)–(12), Eq. 3.2(14); F17/Table H2.1 and rho-b/Table 3.1 |
| Column | F17 hardwood, seasoned, category 1, 5-day duration; 90 × 240 mm; 3,000 mm long; both ends restrained in position and direction; 120 kN compression | Eqs. 3.3(2), (5)–(6), (8)–(9), (11a)–(11c); Tables 3.2–3.3 and H2.1 |
| Tension | F17 hardwood, seasoned, category 2, 5-day duration; 90 × 240 mm; 21,600 mm² net area; 150 kN tension | Eq. 3.4(2), F17 hardwood tension value and size adjustment in Table H2.1 |
| Bearing | F17 hardwood, seasoned, category 2, 5-month duration, EMC 18%; SD2; 90° to grain; 6,750 mm²; 75 mm bearing length and end distance; 25 kN | Eqs. 3.2(15)–(19), Tables 2.1, 2.3, 2.6 and H2.2 |
| Combined compression | Beam and column properties above except category 2, 5-month duration and EMC 18%; 8 kN·m plus 100 kN compression | Both Eqs. 3.5(1) and (2), with capacities independently checked against Sections 3.2 and 3.3 |
| Combined tension | Beam properties above; 8 kN·m plus 150 kN tension and 21,600 mm² net area | Both Eqs. 3.5(3) and (4), with capacities independently checked against Sections 3.2 and 3.4 |

The corresponding complete inputs are in `examples/`. Expected values, tolerances and pass/fail status are generated by `tests/verification_report.py` and written to `validation/benchmarks.json` when run.

## Evidence boundary

Automated arithmetic checks establish that the implementation agrees with the independent calculations for these cases and the selected provisions. They do not establish that an input restraint, strength group, grading certificate, load combination, construction detail, or project-wide design is correct. This release makes no claim of full compliance with AS 1720.1.
